# 👗 Vogue Studio — Apparel & Fashion Brand ERP & POS System
> **Complete Point of Sale, Apparel Inventory, Stitching Orders & Customer CRM**

A comprehensive business management web application tailored for fashion boutiques, apparel brands, and tailor studios in Pakistan. Integrates real-time POS billing, fabric & stitching workflow tracking, customer Khata ledger, and sales analytics.

## ✨ Features & Business Modules

- 💳 **POS Billing & Receipt System:** Fast point-of-sale checkout, discount calculations, tax handling, and instant thermal receipt printing.
- 👗 **Apparel Stock & Inventory:** Track ready-to-wear dresses, fabric yards, sizes (S/M/L/XL), and low-stock automatic alerts.
- ✂️ **Stitching & Order Management:** Custom tailoring measurement logs, fabric status, master tailor assignment, and delivery deadlines.
- 👥 **Customer CRM & Khata Ledger:** Customer contact directory, credit/debit Khata balance tracking, and purchase history.
- 📊 **Sales Analytics & Reports:** Daily/monthly revenue metrics, best-selling apparel categories, and expense breakdown charts.
- 🌙 **Dark Luxury UI:** High-contrast dark theme designed with Outfit & Plus Jakarta Sans typography.
- 💾 **Local Data Backup:** Persistent data storage using browser LocalStorage for offline business continuity.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Custom Variables)
- **Icons & Typography:** Font Awesome 6.4 & Google Outfit / Plus Jakarta Sans Fonts
- **Interactivity:** Vanilla JavaScript (ES6+), LocalStorage API
- **Deployment:** GitHub Pages / Vercel

## 🚀 How to Run Locally

   ```bash
   git clone https://github.com/imaazkhan-web/clothing-brand-manager.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd clothing-brand-manager
   ```

3. **Open in browser:**
   Open `index.html` directly in any modern browser.
